# OctoClaw Archive

This directory keeps historical material that should not be treated as the
current architecture authority.

Use these current entry points first:

- `../octoclaw-ts-rebuild-design-v2.md` — v2 architecture baseline
- `../octoclaw-design-foundation.md` — system definition and invariants
- `../octoclaw-improvement-plan-2026-05-12.md` — current active plan
- `../octoclaw-v0.6.0-roadmap-2026-05-13.md` — current release roadmap

## Contents

- `design-notes/` — design explorations, implementation plans, and router
  designs from 2026-03 through 2026-05. See `design-notes/README.md` for
  a classification table.
- `engineering-log/` — previous planning workspaces, review reports,
  validation packets, acceptance evidence, and old eval reports.

Files here are kept for traceability. They are not active implementation plans
unless a current document explicitly links to them.
