# Engineering Log Archive

This directory contains historical execution artifacts moved out of the active
repository root:

- `planning/`: old `.planning` phase plans, summaries, requirements, roadmap,
  and state notes.
- `sisyphus/`: old `.sisyphus` plans, notepads, and evidence files.
- `omx/`: old OMX planning documents.
- `reports/`: old reply-review, validation, and Slack acceptance reports.
- `eval/reports/`: old generated eval reports.

The files are intentionally kept as historical evidence. Paths mentioned inside
these documents may refer to their original locations.
