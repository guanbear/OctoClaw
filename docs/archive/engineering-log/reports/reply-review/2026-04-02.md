## Improvement Suggestions

### 1. Fix Spawn Execution Pipeline 🔴 Critical
- **Check**: 
  - `spawn_execution.enabled` status in OctoClaw config
  - `openclaw lib/dispatch_task.py` execution path
  - `openclaw skills/octopus/lib/octoclaw_spawn.py` output
  - ClawTeam tmux session health
- **Why**: Spawn execution chain is completely broken; tasks never progress beyond `queued` state

### 2. Capture Route Metadata Consistently 🟡 High Priority
- **Action**: Fix dispatch process to ensure `route` and `system_preferred_route` are always populated when `dispatch_called: True`
- **Benefit**: Enables audit trail, allows verification of routing decisions

### 3. Concise Summaries for "总结一下" Requests 🟢 Medium Priority
- **Rule**: Provide brief bullet-point summary first, offer detailed version as follow-up
- **Example**:
  ```
  **两条主要更新：**
  1. Claude Code 源码泄露
  2. OpenAI 超大融资
  
  需要详细版吗？
  ```

### 4. Clearer Status Communication 🟢 Medium Priority
- **Fix**: Be explicit about current state:
  - "正在调研中，预计1-2分钟完成" (working)
  - "已完成，正在生成报告" (done)
  - "卡在 GitHub 抓取，重试中" (stuck, like Case 8)

### 5. Consider Breaking Changes Warning 🟢 Low Priority
- **Context**: Case 8 mentioned 3 月 31 日 breaking changes (nodes.run removed, plugin install stricter, gateway auth tighter)
- **Suggestion**: When summarizing version updates, explicitly flag breaking changes users should be aware of
