## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native/runtime facts → shared projection builder | Truth is transformed into surface-safe read models |
| shared projection builder → operator renderers | Renderer code consumes projection data and must not re-author truth |
| task anchor commands → user/operator text output | User-visible surfaces expose state and available control actions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03 | T | `lib/runtime_snapshot.py` | mitigate | Build one normalized substrate projection bundle and keep native/source facts explicit so renderers do not mutate authority. |
| T-03-04 | I | `lib/status_render.py` / `lib/task_display.py` | mitigate | Render only from projection fields and keep forbidden inferred fields (`renderer_authored_truth`, `guessed_task_state`) out of the contract. |
| T-03-05 | E | `lib/task_anchor_commands.py` | mitigate | Ensure action availability is projection-backed so command surfaces do not expose unsupported control states based on stale inferred truth. |
| T-03-06 | R | queue/timeline views | accept | Historical timeline completeness depends on existing task/event ledgers; Phase 3 can accept incomplete history if the read path stays source-backed and does not fabricate missing events. |
</threat_model>
