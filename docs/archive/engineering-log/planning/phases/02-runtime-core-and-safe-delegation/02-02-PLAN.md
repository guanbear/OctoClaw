<objective>
Turn the new contracts and policy outputs into executable runtime ownership primitives by building the TypeScript runtime core, the initial runtime adapter seam, and the delegation safety hooks that keep delivery, ownership, and workspace conflict handling inside one rebuild architecture.
</objective>

<threat_model>
- Asset: Runtime ownership and delegation safety code under `packages/octoclaw-runtime-core`, `extensions/octoclaw-runtime`, and `extensions/octoclaw-delegation`.
- Risk: Without idempotent materialization, outbox delivery, or single-owner claims, the rebuild can still create duplicate tasks, double delivery, or competing workers.
- Risk: Without explicit scope and conflict policy, delegated work can corrupt shared workspaces or bypass the rebuild's scheduling guarantees.
- Mitigation: Encode claims, deadlines, delivery receipts, and workspace conflict policy in first-class TypeScript modules and expose the native runtime seam through the TS adapter package rather than Python glue.
- Blocker threshold: Missing outbox or receipt semantics, missing claim ownership enforcement, or delegated tasks without workspace conflict metadata.
</threat_model>
