<objective>
Create the first formal TypeScript contract and policy foundation for the rebuild so later runtime work consumes typed contracts and guarded routing rules instead of reusing Python live-path glue or extending the oversized JS runtime entrypoint.
</objective>

<threat_model>
- Asset: Phase 2 runtime and policy contracts under `packages/octoclaw-contracts` and `packages/octoclaw-policy`.
- Risk: If contracts omit idempotency, ownership, delivery, or scope metadata, later runtime work will recreate hidden side channels or truth drift.
- Risk: If routing logic still allows keyword-based semantic authority or skips admission and capability checks, the rebuild will preserve the instability it is meant to remove.
- Mitigation: Make contract fields explicit, versioned, and testable, and encode the canonical decision stack in one policy layer instead of scattered helpers.
- Blocker threshold: Missing idempotency, claim or lease, scope metadata, or policy support for routes outside `reply`, `delegate.single`, and `observe`.
</threat_model>
