| native truth payloads → projection payloads | Read models are derived from authority data and must not overwrite it |

| T-03-05 | S | `extensions/octoclaw-runtime/index.js` | mitigate | Keep `authority: ts-native-adapter` bound to plugin-produced bindings only; wrapper stub inputs may seed requests but must not overwrite helper-returned truth fields. |
| T-03-06 | I | `extensions/octoclaw-runtime/src/adapter/runtime-taskflow.ts` | mitigate | Continue emitting separate `truth`, `projection`, `artifact`, and `telemetry` families so projection/testing convenience fields cannot become truth inputs. |
| T-03-07 | D | Native helper subprocess path | accept | If OpenClaw or helper invocation fails, fail closed for the native truth path and surface explicit test/runtime errors rather than silently returning synthetic success records. |
